# chaseholroyd.com

Chase Holroyd's portfolio. Plain static HTML served by GitHub Pages.

- Edit page content in `tools/build.py`, then run `python3 tools/build.py` to regenerate the HTML at the repo root.
- Styles: `assets/site.css`.
- `CNAME` points the site at chaseholroyd.com.
- License: site content is all rights reserved (`LICENSE`); the demo apps stay MIT from their source repos.

## How this is built

Built with Claude Code (AI-assisted code, tests and docs). The maintainer directs the work and decides what ships. Tests and CI run on every pull request; the current state is in HANDOFF.md.
