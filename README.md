# chaseholroyd.com

Chase Holroyd's portfolio. Plain static HTML served by GitHub Pages.

- Edit page content in `tools/build.py`, then run `python3 tools/build.py` to regenerate the HTML at the repo root.
- Styles: `assets/site.css`.
- `CNAME` points the site at chaseholroyd.com.
